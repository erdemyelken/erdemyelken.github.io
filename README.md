# Erdem Yelken - Personal Portfolio

🌐 **Live Site:** [erdemyelken.github.io](https://erdemyelken.github.io)

## About

Personal portfolio website showcasing my work as an AI Engineer and PhD Researcher. Features a chess and music-themed design with interactive animations.

## Tech Stack

- Pure HTML5, CSS3, and Vanilla JavaScript
- No frameworks or dependencies
- Fully responsive design
- Animated background elements
- Interactive UI components

## Local Development

Simply open `index.html` in your browser. No build process required.

```bash
git clone https://github.com/erdemyelken/erdemyelken.github.io.git
cd erdemyelken.github.io
# Open index.html in your browser
```

## Features

- 🎨 Animated chess pieces and music notes
- 🎯 Smooth scroll navigation
- 📱 Mobile responsive
- ⚡ Fast loading (no external dependencies)
- 🎭 Interactive hover effects
